# 🚕 NYC Taxi Trip Analysis — Databricks

Analyzing NYC taxi trip patterns using Apache Spark on Databricks Free Edition.

## What This Does
- Loads the NYC Yellow Taxi dataset (public, built into Databricks)
- Aggregates trips by hour of day
- Computes average trip distance and fare per hour

## Tech Stack
- Databricks Free Edition
- Apache Spark (PySpark)
- Python
